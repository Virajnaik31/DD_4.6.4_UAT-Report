## 🚀 Standalone HTML Master Dashboard

To view the interactive master dashboard:
1. Open [`index.html`](./index.html) in any modern browser (Chrome, Edge, Firefox, Safari).
2. Use the live search, module filter buttons, and switch between Cards and Data Table view.
3. Click on any test suite to launch its full interactive Playwright report or view its screenshots & videos in the built-in evidence modal.
